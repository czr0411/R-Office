## How to use
1. Cilck [me](https://czr0411.github.io/R-Office)
2. Enter [czr0411.github.io/R-Office](https://czr0411.github.io/R-Office) at your browser
3. At CMD/Powershell enter `start "https://czr0411.github.io/R-Office"`
4. Use Chrome and press F12, Choose Console and enter JavaScrpit `window.open('https://czr0411.github.io/R-Office', '_blank');`
